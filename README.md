# Lichii Switch 2 Emulator

**Lichii Switch 2 Emulator** (build 177) continues the experimental `nx2` branch off Eglantine, Eden, yuzu, and Sudachi. Existing user directories, saves, and keys stay intact.

## Windows Build Variants (`nx2`)
* **MSVC archive**: Recommended when NVIDIA DLSS via Streamline is required.
* **MinGW PGO archive**: Bundles its own runtime DLLs with no extra Visual C++ package.

<img width="480" height="360" alt="images3" src="https://github.com/user-attachments/assets/b226cc32-aa9c-4679-b707-3352cde79195" />

### Highlights in Build 177
- NVIDIA DLSS Frame Generation / Multi Frame Generation (up to 4x on RTX 50) for Ocarina of Time and FSR3 fallback.
- Wired DualSense HD haptics over USB plus frequency-aware two-motor rumble.
- Fixed OoT dark water grids, Hyrule Field foliage culling, and Mario Kart World sparse memory deadlocks.
